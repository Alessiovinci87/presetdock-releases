# PresetDock — Download

App desktop per Windows che organizza, cataloga e cerca la libreria di preset
che hai già sul computer. Compatibile con i file dei processori Line 6 Helix
e HX (`.hlx`, setlist, `.hsp`).

**[⬇ Scarica l'ultima versione](https://github.com/Alessiovinci87/presetdock-releases/releases/latest)** · [Sito e prezzi](https://presetdock.com)

Questo repository ospita **solo gli installer e gli aggiornamenti automatici**:
il codice sorgente di PresetDock è proprietario e non è pubblico.

L'installer non è ancora firmato digitalmente: al primo avvio Windows
SmartScreen può mostrare un avviso — "Ulteriori informazioni" → "Esegui comunque".
